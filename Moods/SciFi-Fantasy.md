# SciFi-Fantasy — ไซไฟ / แฟนตาซี / โลกเหนือจริง

> โลกอนาคต เทคโนโลยี เวทมนตร์ วิญญาณ หรือโลกที่ไม่มีอยู่จริง
> กลับไปหน้าหลัก: [[Movie-Time]]

## นับเป็นไซไฟ / แฟนตาซีเมื่อ

- ฉากอยู่ในโลกอนาคต โลกอื่น หรือโลกที่มีเวทมนตร์ / สิ่งเหนือธรรมชาติ
- มีแนวคิดหรือกฎของโลกที่น่าสนใจ
